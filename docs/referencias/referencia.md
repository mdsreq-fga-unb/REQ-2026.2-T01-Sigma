# Referências

Este documento reúne as principais referências bibliográficas, metodológicas e técnicas utilizadas no desenvolvimento do projeto **SIGMA**.

## Metodologia e Engenharia de Requisitos

- **OpenUP (Open Unified Process)**: Práticas ágeis e iterativas para desenvolvimento de software e especificação de casos de uso.
- **Engenharia de Requisitos**: Software Engineering: A Practitioner's Approach - Roger S. Pressman.
- **Guia PMBOK**: Um Guia do Conhecimento em Gerenciamento de Projetos.
