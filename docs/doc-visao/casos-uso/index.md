# Casos de Uso

Esta seção reúne as especificações detalhadas dos Casos de Uso (UC) do sistema **SIGMA**, desenvolvidos para a **Creche Estação Vida**.

O detalhamento consolidado da hierarquia de requisitos (Problema ➔ Objetivos ➔ Características do Produto ➔ Casos de Uso), as capacidades funcionais associadas, requisitos não funcionais, regras de negócio e planejamento de entrega do MVP estão disponíveis no [Catálogo Unificado de Requisitos](../8_requisitos.md).
