
# Registros de Definition of Done (DoD)

Esta seção reúne os registros de aplicação do Definition of Done (DoD) nas funcionalidades e incrementos desenvolvidos no projeto SIGMA.

Cada registro deverá corresponder a uma funcionalidade ou incremento específico, apresentando os critérios avaliados, as evidências de implementação e testes, a revisão técnica, a demonstração à equipe e, quando realizada, a validação pela representante do projeto.

## Modelo de avaliação

Utilize o [Modelo de Registro DoD](modelo.md) para documentar cada entrega.

## Registros das entregas

Os registros concluídos ou em andamento serão organizados nesta seção, identificados pela funcionalidade, incremento e versão correspondente.
