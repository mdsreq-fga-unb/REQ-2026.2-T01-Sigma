# Regras de Negócio
 
As Regras de Negócio (RNs) do sistema **SIGMA** foram integradas e consolidadas diretamente no [Catálogo Unificado de Requisitos](8_requisitos.md).

Para consultar a especificação completa, justificativas e rastreabilidade de cada regra de negócio, acesse os cards de casos de uso no Catálogo Unificado e clique nos chips identificadores (ex: **RN01**, **RN02**, ..., **RN22**) para abrir o modal de detalhes interativo.
