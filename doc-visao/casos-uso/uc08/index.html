    UC08 - Consultar Registros (Busca)

    ← Voltar para Casos de Uso

    1. Atores

    Atores principais: Equipe administrativa: (Secretárias, Coordenadoras e Diretora).

    2. Objetivo

    Permitir que a secretária autenticada busque alunos por nome completo ou parcial para abrir o card do aluno, bem como busque turma e etapas cadastradas no sistema, garantindo agilidade no atendimento e na localização de informações.

    3. Pré-Condições

    • O ator deve estar autenticado no sistema (RF06).
    • A conta do ator deve estar com status "Ativo" (RN18).
    • O sistema deve possuir conexão com backend para consultar os dados.
    • Para buscar alunos, deve haver alunos previamente cadastrados.
    • Para buscar turmas e etapas, deve haver turmas e etapas previamente cadastradas.

    4. Fluxo Principal

    FP01 - Buscar Aluno pelo Nome

    1. O ator acessa a funcionalidade de busca de alunos no sistema. (RF21)
    2. O sistema exibe o campo de busca.
    3. O ator informa o nome completo ou parcial do aluno. (RF21)
    4. O sistema processa a busca ignorando maiúsculas, minúsculas e acentos. (RF21)
    5. O sistema retorna os resultados em até 2 segundos para 95% das requisições. (RNF06)
    6. O sistema exibe a lista de alunos encontrados com seus cards.
    7. O ator seleciona um aluno da lista.
    8. O sistema abre o card do aluno com os dados de registro de matrícula. (RF21)
    9. O sistema encerra o caso de uso.

    FP02 - Buscar Turmas e Etapas

    1. O ator acessa a funcionalidade de busca de turmas e etapas no sistema. (RF22)
    2. O sistema exibe o campo de busca.
    3. O ator informa o nome completo ou parcial da turma ou etapa. (RF22)
    4. O sistema processa a busca.
    5. O sistema retorna os resultados em até 2 segundos para 95% das requisições. (RNF07)
    6. O sistema exibe a lista de turmas e etapas encontradas, incluindo aquelas com status "inativo" identificadas. (RN12)
    7. O ator visualiza os resultados.
    8. O sistema encerra o caso de uso.

    5. Fluxos Alternativos

    FA01 - Nenhum Aluno Encontrado

    1. O ator realiza a busca de aluno. (RF21)
    2. O sistema consulta a base de dados.
    3. O sistema não encontra registros correspondentes ao critério informado.
    4. O sistema exibe a mensagem: "Nenhum resultado encontrado."
    5. O sistema mantém o campo de busca disponível para nova tentativa.

    FA02 - Nenhuma Turma ou Etapa Encontrada

    1. O ator realiza a busca de turma ou etapa.
    2. O sistema consulta a base de dados.
    3. O sistema não encontra registros correspondentes ao critério informado.
    4. O sistema exibe a mensagem: "Nenhum resultado encontrado". (RF22)
    5. O sistema mantém o campo de busca disponível para nova tentativa.

    FA03 - Busca com Acentos ou Maiúsculas/Minúsculas

    1. O ator informa o nome com acentos ou variação de maiúsculas/minúsculas. (RF21)
    2. O sistema normaliza os dados de entrada e da base (remoção de acentos, conversão para minúsculas).
    3. O sistema retorna os resultados correspondentes. (RF21)

    6. Fluxos de Exceção

    FE01 - Falha de Conectividade

    1. O ator tenta realizar uma busca. (RF21, RF22)
    2. O sistema não consegue se conectar ao backend.
    3. O sistema não concluiu a operação.
    4. O sistema exibe mensagem de falha de conexão.
    5. O sistema orienta o ator a tentar novamente quando a conexão for restabelecida.

    FE02 - Erro interno no banco de dados

    1. O ator realiza uma busca válida. (RF21, RF22)
    2. O sistema tenta consultar os dados no banco.
    3. O banco de dados retorna erro ou indisponibilidade.
    4. O sistema cancela a operação.
    5. O sistema exibe mensagem de erro interno.

    FE03 - Tentativa de Acesso sem Autenticação

    1. O ator tenta acessar a funcionalidade de busca sem estar autenticado. (RF21, RF22)
    2. O sistema identifica a ausência de sessão válida.
    3. O sistema bloqueia o acesso.
    4. O sistema direciona o ator para a tela de autenticação. (RF06)

    FE04 - Conta com Status "inativo"

    1. O ator tenta acessar a funcionalidade de busca com conta inativa. (RN18)
    2. O sistema identifica que a conta está inativa.
    3. O sistema bloqueia o acesso ao sistema.
    4. O sistema informa ao ator que a conta está inativa.

    7. Regras de Negócio

    ID Regra de Negócio Aplicação no UC08 Justificativa
    RN07 Impedir cadastro de dois alunos com a mesma matrícula ou CPF Garante que os resultados da busca sejam únicos e não duplicados Evita conflito de dados.
    RN11 Só turmas e etapas ativas podem receber novos vínculos A busca pode retornar turmas/etapas inativas, mas elas não podem receber novos alunos Evita alocar matrículas em estruturas inativas.
    RN12 Inativar uma turma ou etapa não elimina os vínculos existentes Turmas/etapas inativas aparecem na busca, identificadas com status "inativo" Preserva o histórico de alocação dos alunos.
    RN13 Impedir cadastro de duas etapas com o mesmo nome Garante que a busca por etapas não retorne duplicatas Evita conflito de dados.
    RN14 Impedir cadastro de duas turmas com o mesmo nome dentro da mesma etapa Garante que a busca por turmas não retorne duplicatas dentro de uma mesma etapa Evita conflito de dados.
    RN18 Apenas contas com status "Ativo" podem acessar o sistema Impede que contas inativas realizem buscas Garantir que ex-funcionários e/ou pessoas não autorizadas percam acesso total ao sistema e aos dados nele contidos.

    8. Requisitos Relacionados

    RF/RNF Relação com o UC
    RF21 - Buscar aluno pelo nome Permite que a secretária busque alunos por nome completo ou parcial, sem diferenciar maiúsculas, minúsculas e acentos, retornando os dados de registro de matrícula.
    RF22 - Buscar turmas e etapas Permite que a secretária busque turmas e etapas por nome completo ou parcial, exibindo mensagem "Nenhum resultado encontrado" quando não houver registros.
    RNF06 - Tempo de resposta para buscar aluno Retornar os resultados da consulta de alunos em menos de 2 segundos para 95% das requisições.
    RNF07 - Tempo de resposta para buscar turmas ou etapas Retornar os resultados da busca de turmas ou etapas em menos de 2 segundos para 95% das requisições.
