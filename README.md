**SIGMA (Sistema Integrado de Gestão de Matrículas)** é uma proposta de software desenvolvida no âmbito da disciplina de Requisitos de Software na Universidade de Brasília (UnB - FGA). O sistema foi concebido para atender às demandas de gestão da **Creche Estação Vida**, modernizando o processo de cadastro, preenchimento de fichas e organização de matrículas, atualmente realizado de maneira manual.

## Acessar Documentação

Link: https://mdsreq-fga-unb.github.io/REQ-2026.2-T01-Sigma/

## Cliente do Projeto

- **Organização:** Creche Estação Vida
- **Natureza:** Instituição de ensino filantrópica e sem fins lucrativos
- **Localização:** Águas Lindas de Goiás
- **Atendimento:** 202 crianças em situação de vulnerabilidade social
- **Representante:** Cirlene Sena (Diretora)
